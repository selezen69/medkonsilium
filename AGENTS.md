# МедКонсилиум

Работать только с этим медицинским проектом. Репозитории design и igormed не являются источником кода приложения.

Сначала читать medconsilium-spec-v1.md и README.md. Основной путь: вопрос, затем необязательные документы.

- Node.js 24+, без обязательных внешних пакетов. Не выдавать незавершённые функции ТЗ за готовые.
- Проверять права на сервере для каждого обращения к профилю и его данным.
- Автор действия и владелец медицинского профиля могут различаться; администраторский доступ не объединяет контекст семьи.
- Все данные примеров и тестов — вымышленные. Не коммитить .env, data, записи или медицинские документы.
- Результаты ИИ отличать от установленных диагнозов и назначений. Не подменять отключённый API демонстрационными медицинскими ответами.
- При изменениях доступа, хранения или ИИ запускать npm run check и npm test.
- Изменения разработки сохранять в medconsilium-v1; не сливать в main и не публиковать без соответствующей задачи.
